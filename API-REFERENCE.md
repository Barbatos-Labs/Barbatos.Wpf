# Barbatos.Wpf API Reference

Barbatos.Wpf ships as four independent packages, each with its own full API reference. The
namespaces below are every namespace that declares public types:

- **[Barbatos.Wpf.Core API Reference](https://github.com/Barbatos-Labs/Barbatos.Wpf/blob/main/src/Barbatos.Wpf.Core/API-REFERENCE.md)** -
  `Barbatos.Wpf.Hosting`, `Barbatos.Wpf.LifecycleEvents`, `Barbatos.Wpf.Dispatching`,
  `Barbatos.Wpf.ApplicationModel`, `Barbatos.Wpf.ApplicationModel.Communication`,
  `Barbatos.Wpf.Devices`, `Barbatos.Wpf.Devices.Sensors`, `Barbatos.Wpf.Networking`,
  `Barbatos.Wpf.Storage`, `Barbatos.Wpf.Tray`, `Barbatos.Wpf.Power`, `Barbatos.Wpf.Startup`,
  `Barbatos.Wpf.Input`, `Barbatos.Wpf.Notifications`, `Barbatos.Wpf.PushNotifications`,
  `Barbatos.Wpf.SingleInstance`, `Barbatos.Wpf.Dialogs`, `Barbatos.Wpf.Apsu`, `Barbatos.Wpf.Mcp`.
- **[Barbatos.Wpf.Aquarius API Reference](https://github.com/Barbatos-Labs/Barbatos.Wpf/blob/main/src/Barbatos.Wpf.Aquarius/API-REFERENCE.md)** -
  `Barbatos.Wpf.Aquarius.Reactivity`, `Barbatos.Wpf.Aquarius.Composition`,
  `Barbatos.Wpf.Aquarius.Xaml`, `Barbatos.Wpf.Aquarius.Animation`.
- **[Barbatos.Wpf.AquariusRouter API Reference](https://github.com/Barbatos-Labs/Barbatos.Wpf/blob/main/src/Barbatos.Wpf.AquariusRouter/API-REFERENCE.md)** -
  `Barbatos.Wpf.AquariusRouter.Matching`, `Barbatos.Wpf.AquariusRouter.Routing`,
  `Barbatos.Wpf.AquariusRouter.Searching`, `Barbatos.Wpf.AquariusRouter.Xaml`.
- **[Barbatos.Wpf.AquariusValee API Reference](https://github.com/Barbatos-Labs/Barbatos.Wpf/blob/main/src/Barbatos.Wpf.AquariusValee/API-REFERENCE.md)** -
  `Barbatos.Wpf.AquariusValee.Validation`, `Barbatos.Wpf.AquariusValee.Rules`,
  `Barbatos.Wpf.AquariusValee.Xaml`.

Core's `Barbatos.Wpf.Mcp.Providers` namespace holds only `internal` provider implementations
behind the public `Barbatos.Wpf.Mcp` interfaces, so it has no reference entry.

See the [root README](https://github.com/Barbatos-Labs/Barbatos.Wpf#readme) for an overview of all four packages.
